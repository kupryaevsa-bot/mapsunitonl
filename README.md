# mapsunitonl — карта юнита: сектор №56

Выгрузка сектора **№56** 2D-сборки карты (проект «Сборка карты», `world_memory.json`).

## Сектор №56

- Координаты: **x 700–799, y 400–499** (56-й сектор рабочего региона 12×13, x 0–1199 / y 0–1299)
- 100 × 100 игровых клеток = **50 × 50 тайлов = 2500** тайлов земли
- **1856 объектов**, **3890 спрайтов**, уровни 0–4
- Покрытие земли 100 %, пропущенных PNG — 0
- В диагональном атласе это кадр **№16 «Кирпичный квартал»**

## Как собирается карта

1. Дампы (`pcap`/`txt`) разбирает `farm/dump_import.py`: из пакетов `sb/ub` берётся земля
   `{i, j, level, id}`, из `ol` — объекты `{oid, i, j, level, depth, type, sprites[ox, oy, pack, image, frames, hide]}`.
2. Всё сливается в `world_memory.json`. Один тайл = 4×4 клетки (шаг 4 по `i`/`j`),
   мировые координаты `x = j/2`, `y = i/2`.
3. Изометрия: `sx = (i + j) * 16`, `sy = (i − j) * 8 − level * 85`.
   Рисунок тайла 128×64 px кладётся в `(sx − 32, sy − 32)`, спрайт объекта — в `(sx + ox, sy + oy)`.
4. Порядок: тайлы `(level, i+j, i, j)`, объекты `(level, depth, oid)` — дальние рисуются первыми.
5. Сектор вырезается прямоугольником x 700–799 / y 400–499 и рендерится в PNG/JPEG
   тем же кодом, что и 2D-сборка в приложении.

## Пересборка

```bat
python tools/export_sector_56.py
```

Скрипт читает `world_memory.json` (лежит рядом с приложением «Сборка карты» и в репозиторий
не входит — 64 МБ) и заново создаёт папку выгрузки.
